## 开场（00–05）· 喂没喂过资料，差多少

- **演示对比**，课前做好截图：
  - 不喂资料，直接问：“帮我写一段，为什么回收要先查验再报价。”AI 给出一段谁都能发的标准答案。
  - 先喂三样：我以前讲过的口播、一段接待录音、我的报价原则。再问同一个问题，回答就像我说的，还能指出每句话出自哪里。
- 参考课的说法：不喂资料，最好的模型也只有 80–85 分。
- 回扣上节课第 7 页：“它能干多好，取决于你给它多少。”知识库，就是装“给它多少”的那个仓库。

## 第一部分（05–18）· 知识库是什么、不是什么

**是什么**：
- 知识库是一个决策系统，存的是你怎么想、怎么做、怎么判断。
- 二奢版的比方：店里干了十年的老师傅，知道哪类客户爱砍价、哪类货好走、什么成色报什么区间。知识库就是把老师傅的这些判断装进 AI。参考课用的是“买房中介”的比方，可以换成这个。

**不是什么**：网上的文章、书、行业常识，大模型早就学过了，再存一遍没意义。

**知识库和记忆的分工**（参考课）：
- 知识库解决“找得到”。
- 记忆解决“下次还想得起来”。

**五个误区**：

| 误区 | 真相 |
|---|---|
| 要一次性建好 | 知识库是每天用出来的，不是一次搭出来的 |
| 存得越多越好 | 存你自己的第一手东西，网上能搜到的不用存 |
| 要买很贵的工具 | 一个文件夹 + 一个能读文件的 AI 就能起步；套餐够用就行（参考课） |
| 建好就完事 | 不用就是死库。每次用完说一句“加入知识库” |
| 什么都往里丢 | 身份证、银行卡、手机号不进库，客户的、自己的都不行 |

## 第二部分（18–30）· 存什么：二奢老板的 10 个素材来源

核心原则（参考课）：**第一手的原始数据最值钱。** 素材越真、越细，AI 越懂你。

**录音类**，讲师原来提的四条，加上展开：

| 来源 | 怎么收 | 存进去有什么用 |
|---|---|---|
| 1. 接待客户（回收、销售） | 接待时录音，转成文字，删掉姓名电话 | 客户原话、真实顾虑、报价怎么谈下来的 → 话术、证言、选题 |
| 2. 日常感悟 | 开车、散步时用录音笔或手机录，转文字 | 你的观点和口头禅 → 观点型朋友圈、口播 |
| 3. 工作会议、员工复盘 | 会议录音，转成会议纪要 | 决策过程和理由 → 经营复盘 |
| 4. 拍视频、直播 | 录制时顺手录音，或者回放转文字 | 你讲过的干货 → 一鱼多吃 |
| 5. 外部链接和资料 | 公众号文章、同行爆款、网页，用采集工具抓下来 | 拆别人的写法、补行业信息 |

**录音之外再补五样**（新增）：

| 来源 | 存进去有什么用 |
|---|---|
| 6. 成交和报价记录（表格） | 下次报价有依据，查同款历史成交 |
| 7. 好评、证言截图（打码） | 朋友圈证言型、私聊发证据 |
| 8. 自己写过的爆款文案、朋友圈 | 风格样本，AI 学你的口气 |
| 9. 踩过的坑、遇到的骗局 | 防骗清单、新员工培训（11/11 防骗课的素材） |
| 10. 店里的 SOP 和月度经营数据 | 新人培训、月度复盘 |

**工具**（讲前核实名字和现状）：
- 录音笔：参考课用的是 Plaud；10/7 课上讲过录音笔，也可以用手机录。
- 转文字：Get 笔记、飞书、讯飞这类工具都可以。
- 外部链接采集：参考课里是 Agent Reach、Open CLI。
- 讲师确认：外部链接采集用 WorkBuddy。

**红线**：身份证、银行卡、手机号不进知识库，客户的和自己的都不行。知识库就是一个文件夹，谁拿到你的电脑或账号就能全看到。

## 第三部分（30–40）· 怎么搭：一个文件夹、十个格子、三类内容

**工具分两档**：
- **起步**：ima、飞书知识库这类工具，手机就能用，按主题建库。不同主题不要混在一个库里。
- **进阶**：电脑上建一个“知识库”文件夹，用 WorkBuddy 这类能读文件的 AI 去读。换工具、换模型，文件夹都不用动（参考课：始终在同一个文件夹里干活）。

**二奢版文件夹框架**（参照参考课的十个子文件夹改写）：

| 编号 | 文件夹 | 放什么 |
|---|---|---|
| 00 | 待整理 | 当天的录音、文章先扔这里，每周整理一次 |
| 01 | 客户原话 | 接待录音的文字稿（已脱敏） |
| 02 | 报价与成交 | 成交记录、报价依据 |
| 03 | 内容素材 | 选题、爆款拆解、朋友圈、口播稿 |
| 04 | 我的观点 | 日常感悟、对行业和生意的判断 |
| 05 | 会议与复盘 | 会议纪要、月度复盘 |
| 06 | 话术库 | 回收线、销售线话术（10/21） |
| 07 | SOP | 收货、上架、发货、售后流程 |
| 08 | 风控与踩坑 | 骗局案例、收货核查清单 |
| 09 | 经营数据 | 库存表、月度数据 |
| 10 | 外部资料 | 链接、文章、同行案例 |

**三个说明文件**（参考课）：
- **README**：告诉 AI 这个文件夹是干什么的，里面有哪些格子。
- **索引**：AI 先看索引再去找，省时间、省积分。
- **核心认知**：你的定价原则、做事方法、价值观，每次聊完都往里加。

**三类内容**（参考课的说法，换成二奢的例子）：
- **长期认知**：比如“超过 30 天的货必须动”“先查验再报价”。
- **当前工作**：比如这个月双 11 在做什么、做到哪一步。
- **证据**：每个判断出自哪段录音、哪单成交。

**命名**：`日期_主题_来源`，例如 `1103_回收LV客户_接待录音`。

## 第四部分（40–50）· 怎么用：10 个用法

讲师原有的三个：

1. **写文案**：口播、短视频，用你的说法写。
2. **朋友圈**：从客户原话、感悟里出一周 7 条（10/7 提示词）。
3. **经营思考**：参考课叫“洞察对话”。
   - 把这周的会议记录拖给 AI，说：“结合知识库，我们来讨论双 11 要不要降价。”
   - 让它反驳你，辩三到五轮。
   - 聊完说一句：“把这次的结论加入知识库。”

再拓展七个：

4. **话术和客服**：客户问到新问题，先查库里以前怎么答的、哪次答完成交了。
5. **新员工培训**：员工有问题先问 AI，等于问老板。参考课里讲师给客服和销售做了内部 AI 助教。
6. **报价依据**：查同款历史成交、成色和价格的关系。⚠️ 最终价你定。
7. **选题库**：客户反复问的问题，就是最值钱的选题。
8. **证言和案例**：找出“比视频里还新”这类客户原话，做朋友圈证言。
9. **防骗核查**：收货前对照库里的骗局案例和核查清单。
10. **人设一致**：AI 写的东西都按你库里的观点写，人设不会说一套做一套。

## 第五部分（50–57）· 现场演示

**演示 1：一段接待录音进库**
1. 录音转文字，删掉客户姓名、电话。
2. 放进“01 客户原话”。
3. 让 AI 结合知识库，出三样东西：这位客户的 3 个顾虑；1 条话术改进；2 条朋友圈。

**演示 2（选做）：洞察对话 3 轮**
- 话题：“双 11 要不要给超 30 天的货降价。”
- 让 AI 引用库里的定价原则来反驳你。

## 收尾（57–60）

**养库习惯**：
- 每天一句：用完说“加入知识库”。
- 每周一次：整理“待整理”文件夹。
- 不为了优化而优化，在真实的活里用，越用越好（参考课）。

**作业**：
- **起步店**：建好十个格子的文件夹，这周录 3 段接待录音，转好文字放进去。
- **成熟店**：写好 README 和“核心认知”文件，做一次洞察对话。

**预告**：Skill 专场，把知识库和规则装进技能。也可以接双 11。
