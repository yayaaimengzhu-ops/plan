# 附：二奢老板日常能交给 AI 的事

> 用法：配合 10/28 课。
> - **想**：用 Chat 陪你想，你在场，它问你答。
> - **干**：用 Work 替你干，把文件夹和要求交代清楚，回来验收。
> - **想 → 干**：先在 Chat 里想清楚，再交给 Work 批量做。
>
> 每条后面写了“给它什么 → 它给你什么”。“⚠️”是这件事里必须你拍板的部分。

---

## 一、经营决策：大方向

| 事情 | 想 / 干 | 给它什么 → 它给你什么 |
|---|---|---|
| 店铺定位 | 想 | 让它按三角图（人设、人群、需求）反问你 → 3 句定位备选（10/14） |
| 现在处在哪个阶段 | 想 | 说清年毛利、人数、主营 → 对照阶段打法，告诉你该加什么、该砍什么（10/14） |
| 品类取舍 | 干 | 近 3–6 个月的销售表 → 各品类毛利、周转天数排行，哪些在拖后腿（06-24 砍低效品类） |
| 要不要做新品类、开新店、做 B 端 | 想 | 讲清楚你的钱、人、货 → 正反两面清单，加你没想到的风险 ⚠️ 决定你来做 |
| 季度 / 年度规划 | 想 → 干 | 先聊清目标，再让它排成按月的计划表、甘特图（06-24） |
| 行业消息整理 | 想 | 把看到的新闻、政策贴给它 → 对你店里有什么影响 ⚠️ 数字和原文自己核实 |
| 价格带分析 | 干 | 你自己的成交记录 → 哪个价位卖得快、哪个压货 |

## 二、货和钱：库存、定价、财务

| 事情 | 想 / 干 | 给它什么 → 它给你什么 |
|---|---|---|
| 库存预警 | 干 | 库存表 → 超 30 天的货按压款金额排序，加处理建议（07-15 周转纪律） |
| 每周库存周报 | 干 | 设定时任务，每周一自动出（03-24、06-24） |
| 记账分类 | 干 | 流水截图或表格 → 按收入、成本、费用分好类（07-15 AI 记账） |
| 现金流测算 | 想 → 干 | 说清回款周期、固定开支 → 未来 3 个月的现金流表，哪个月会紧 |
| 利润测算 | 干 | 一单的收价、卖价、费用 → 毛利、净利、年化（07-15 利润公式） |
| 报价依据整理 | 干 | 同款近期成交记录 → 整理成报价依据表，方便跟客户讲清楚 ⚠️ 最终报价你定 |
| 寄卖、回收协议初稿 | 想 | 你的流程和规矩 → 协议条款初稿 ⚠️ 必须找律师看过再用 |
| 税务问题先理思路 | 想 | 把你的情况讲给它 → 问清楚该问会计什么 ⚠️ 以会计和税务部门为准 |

## 三、招人和带团队

| 事情 | 想 / 干 | 给它什么 → 它给你什么 |
|---|---|---|
| 想清楚要不要招、招什么岗 | 想 | 说清你每天时间花在哪 → 哪些活该交出去（07-15：招人只看能不能解放你） |
| 写招聘启事 | 想 | 岗位要干的活 → 招聘文案 ⚠️ 不写性别、婚育这类限制，容易违规 |
| 面试题 | 想 | 岗位 → 10 道面试题，加“好回答 / 差回答”的样子 |
| 新人培训手册 | 想 → 干 | 你口述收货、接待、打包、售后流程的录音 → 整理成 SOP 手册 |
| 新人陪练 | 想 | 让 AI 扮演难缠客户，新人来接，练完让它打分（10/21 话术、08-12 Agent 对练） |
| 提成和绩效方案 | 想 | 说清你想鼓励什么 → 几套方案，加各自的坑 |
| 排班表 | 干 | 人员和营业时间 → 一周排班表 |
| 周会议程、员工日报汇总 | 干 | 员工交来的日报 → 一页周报：做了什么、卡在哪 |
| 难开口的谈话 | 想 | 要批评员工、谈涨薪、谈离职 → 先和它演练一遍怎么说 |

## 第一批先做的 10 件（推荐给学员）

挑的标准：天天都要做、交给 AI 省时间最多、出错风险最小。

1. 录音逐字稿 → 一周朋友圈（干）
2. 让 AI 反问你，写定位句（想）
3. 库存表 → 超 30 天预警（干）
4. 话术库，加 AI 扮演砍价客户陪练（想 → 干）
5. 一个文件夹的货品信息 → 批量上新描述（干）
6. 口述流程 → 收货、发货 SOP 手册（想 → 干）
7. 双 11 活动方案和倒排时间表（想 → 干）
8. 发布前合规检查（干）
9. 直播回放 → 切片选题和口播稿（干）
10. 每周一自动出库存周报（干，定时任务）

## 三条底线（所有事情都适用）

1. **真假、报价、收不收、赔不赔，你拍板。** AI 只整理依据。
2. **客户姓名、电话、身份证、银行卡先删掉，再交给 AI。** Work 只给它一个文件夹。
3. **合同、税务、平台规则，AI 只帮你理思路。** 最后以律师、会计、平台原文为准。
