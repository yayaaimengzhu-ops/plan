# 10/28 Skill 专场：把你的经验做成 AI 技能

- **板块**：AI 提效
- **时长**：60 分钟
- **适合**：已经装好 WorkBuddy 的学员；没装的跟着看，课后补装
- **本课最想讲的一句话**（草稿，可改）：
  > “提示词是一次性的，Skill 是一辈子的。把你磨好的东西装进去，AI 才真的成了你的员工。”

## 为什么这节课现在讲
- **兑现承诺**：07-01 课上说过“后续安排专场课程，教大家自己创作个人专属 Skill”。
- 学员手里已经有原材料了：07-01 的三库和调教规则、09-09 的红线、10/21 的话术库 v1，这节课只是把它们“装进去”。
- 平台在 8 月底收紧了导流规则，正好用一个“合规审核 Skill”帮所有学员一次性堵住风险。

## 本课交付物
三个 Skill，现场做出来：
1. **二奢发布前合规审核**（所有人都要做，下面给出完整 SKILL.md 示例）
2. **我的口播风格**（给框架，学员填自己的样本）
3. **成交话术助手**（用 10/21 的话术库 v1）

## 课前准备
- **讲前实测** WorkBuddy 当前版本新建 Skill 的入口。查到的三种方式见第二部分，界面以实测为准。
- 提前在自己电脑上把三个 Skill 各跑通一次，录屏备用，防止现场卡顿（03-24 实操课遇到过安装慢）。
- 准备 5 条“有问题”的旧脚本（含联系方式、绝对化用语、白大褂等），现场给合规 Skill 审。

## 第一部分（03–10）· Skill 是什么

**回顾 2 分钟**：06-10 讲过“网页端的大模型只有大脑，要让它有手脚就得装技能”；04-08 讲过“你把巴菲特的思维喂给它，它就按那套流程做事”。

| 东西 | 是什么 | 打个比方 | 缺点 |
|---|---|---|---|
| 提示词 | 一次性的指令 | 每次口头交代员工 | 每次都要重说 |
| 知识库 / 三库 | 资料（07-01 的选题库、结构库、素材库） | 员工手边的资料柜 | 有资料不等于会干活 |
| 记忆 | AI 记住的你（06-10 的三文件） | 员工对你的了解 | 不稳定，会混（08-12 的“记忆污染”） |
| **Skill** | **一份写清楚“什么时候、按什么步骤、做成什么样”的说明书** | **岗位 SOP** | 要花一次功夫写 |

可以这样说：“你招个员工，第一天就要给新人一份岗位 SOP。Skill 就是 AI 员工的岗位 SOP，写一次，以后每次都按这个做。”

---

## 第二部分（10–18）· 好 Skill 的六个部分 + 三种创建方式

### 好 Skill 的六个部分
1. **什么时候用**（触发条件）
2. **需要我给什么**（输入）
3. **按什么步骤做**
4. **输出长什么样**（格式）
5. **绝对不能做什么**
6. **一个好例子**

### 在 WorkBuddy 里创建的三种方式（以讲前实测为准）
1. **图形界面**：个人中心 → 设置 → Skills 管理 → 新建技能。
2. **放文件**：写一个 `SKILL.md`（开头是名称和描述，下面是正文），放到 WorkBuddy 的本地 skills 目录，然后重启。
3. **用说的**：在对话里直接说“帮我把下面这份规则做成一个 Skill”，让它自带的 skill 创建能力帮你生成。

> 推荐给学员的是第 3 种：把下面的示例整段粘贴进去，说“照这个格式帮我做成 Skill”。

## 第三部分（18–45）· 现场做三个 Skill

### Skill ①：二奢发布前合规审核（完整示例，学员可以直接复制）

这一个 Skill 把 09-09 的内容红线、引流红线，07-22 的合规词表，03-24 你自己的硬规则（文案不出现“鉴定”），以及 AI 内容标识要求全部装进去了。

```markdown
---
name: 二奢发布前合规审核
description: 在我发布短视频脚本、标题、字幕、主页简介、朋友圈、团购文案之前使用。逐条检查平台红线和广告用语，输出风险等级、问题清单和改好的版本。
---

# 二奢发布前合规审核

## 什么时候用
我发来一段准备发布的文字，并说“审一下”。

## 步骤
1. 先问清楚发在哪：抖音 / 视频号 / 小红书 / 朋友圈 / 大众点评 / 抖音团购。
2. 按“检查清单”逐条检查，一条都不能漏。
3. 按“输出格式”给结果。

## 检查清单
### A. 导流（最高风险，会直接封号）
- 公域内容或抖音私信里出现微信号、手机号、二维码，或者用谐音、拼音、拆字、图片藏号码 → 高风险
- “加我微信”“私我拿资料”这类明着导流的说法 → 高风险
- 在抖音里谈具体业务（报价、看真假、帮收），而且和账号报白的类目对不上 → 高风险

### B. 内容红线
- 画面或文案里出现穿医护等公职制服的人（没有资质认证）
- 承诺效果：“百分百赚钱”“保证卖高价”“稳赚不赔”
- 玄学、医疗话题；提到法院、公安、海关等公职机构
- 脏话、低俗
- 未成年人出镜卖包；客户隐私没打码（人脸、证件、车牌、聊天记录里的手机号）

### C. 广告用语
- 绝对化用语：“最”“第一”“全网最低”“最高价”“顶级”
- 拿不出证据的数据和对比

### D. 我店的硬规则
- “回收”尽量改成“出手 / 变现 / 置换”
- 文案不出现“鉴定”，改成“查验 / 检测 / 看货”
- 不说别人的东西是假的

### E. AI 内容标识
- 画面或配音是 AI 生成的，提醒我发布时打开平台的“AI 生成”标识

### F. 精准度提醒（不是违规，但要提醒）
- 换产品测试：把文中的奢侈品换成一瓶汽水，故事还成立吗？成立就提醒我“内容偏泛，可能吸来看热闹的人”

## 输出格式
1. 风险等级：高（可能封号）/ 中（可能限流或被删）/ 低（建议优化）
2. 问题清单：原句 → 问题 → 改写建议
3. 改好的完整文本

## 绝对不要
- 规则拿不准时不要说“平台一定不管”，标成“需人工确认”
- 不要删掉我的口头禅和语气词，只改有风险的地方
- 不要编造平台规则

## 例子
输入：今天医院门口收了个护士的包，想出手的姐妹加我 V：xxxx
输出：
- 风险等级：高
- 问题：① 出现联系方式（导流）；② 如果画面里有人穿白大褂，属于公职制服风险
- 改写：今天在医院附近收了一只包，背后的故事有点暖……想了解的可以看我主页合集
```

**现场演示**：把准备好的 5 条“问题脚本”一条条丢进去，让学员看它抓出了什么。最后说：“以后你和员工发任何东西之前，先让它审一遍。”

### Skill ②：我的口播风格（给框架，学员填自己的）

**承接旧课**：07-01 的口播调教闭环（“调完让它把规则记下来”）和风格喂养三条路。

```markdown
---
name: 我的口播风格
description: 写短视频口播稿时使用，让稿子像我本人说的话。
---

## 需要我给什么
- 选题一句话
- 用哪个结构（从结构库里选）
- 相关素材（从素材库里选）
- 目标时长

## 步骤
1. 先读“素材库/我的爆款口播样本”（5–10 条）
2. 按选定的结构写初稿，字数按每分钟 150–200 字计算（05-13）
3. 自查三件事：
   - 开头 5 秒有没有钩子（否定句、数字、悬念）
   - 有没有 AI 味（“首先、其次、总而言之”这类）
   - 结尾有没有商家味（07-01：结尾要留白，不推销）
4. 写完调用“二奢发布前合规审核”再查一遍

## 我的说话习惯
（让 AI 从你的爆款样本里提炼，例如：口头禅、常用的比喻、句子长短、常用的开头方式）

## 绝对不要
- 不编造客户故事和数字（04-15：流程可以演，数字不能造）
```

### Skill ③：成交话术助手（用 10/21 的话术库）

```markdown
---
name: 二奢成交话术助手
description: 客户在微信里发来消息时，帮我给出回复建议。
---

## 需要我给什么
- 客户的聊天截图或原话（先把手机号、身份证号打码）
- 客户标签：买还是卖、预算、品牌偏好

## 步骤
1. 判断客户处在哪一步：首问 / 看货 / 报价 / 比价 / 犹豫 / 约时间 / 打款 / 售后
2. 从话术库里找最接近的场景
3. 给出两个回复：一个稳妥版，一个推进版；再写下一步动作
4. 标出风险：未成年、身份不一致、白嫖、骗局信号（11/11 会补充骗局清单）

## 话术库
（粘贴 10/21 作业里的《话术库 v1》）

## 绝对不要
- 不替我承诺价格底线和售后承诺以外的事
- 不编造“有人在问”“马上涨价”
```

可以这样说：“这三个 Skill 是互相调用的：写稿用 ②，发之前用 ① 审，客户来了用 ③ 接。”

---

## 第四部分（45–52）· 安全与维护

1. **只装官方或自己建的 Skill**：03-19 讲过，第三方技能包已经出过账号信息泄露的事。
2. **放在沙箱里**：一个项目一个文件夹（06-10、08-12），Skill 只读写它需要的那个文件夹。
3. **加版本号**：v1、v2……每次改了什么记一句，改坏了能退回去。
4. **回写**：每次你手动改了 AI 的稿子，就让它把“这次改了什么”写回对应 Skill 的规则里（07-01 的规则固化）。
5. **敏感信息不进 Skill**：客户的身份证、手机号、银行卡一律不放。
