## 一、Toby：朋友圈成交体系

### 1. 他怎么看朋友圈
- 朋友圈是“离钱最近的地方”。分工是：小红书拉新，视频号建立信任，朋友圈负责成交，一对一私聊只是“临门一脚”。
- 朋友圈有人看，只是大多数人不点赞。早上起床、睡觉前，大家都在刷。
- 衡量一条朋友圈好不好，只看一件事：客户看完有没有“一点点心动”。

### 2. 三大类、八个模板

| 大类 | 模板 | 怎么写 | 要点 |
|---|---|---|---|
| 让人认识你 | ① 连续剧栏目 | 起一个栏目名，加 #，加期数，每期只讲一个点，顺带带出业务 | 广告变成“追剧”，让人想往回翻。例：#每天一个好消息 第 99 天 |
| | ② 真人照片 | 每条都配自己的照片；营销帖第一张必须是自拍，“对冲”营销味 | 照片比文案更快建立信任；不用精修，人要在业务场景里 |
| 让人信任你 | ③ 专业判断 | 一个问题 + 一个明确答案 + 理由；用问句开头 | “你以为是 A，其实是 B”。客户反复问的问题，就是最值钱的选题库 |
| 让人主动成交 | ④ 客户证言 | 60 分：支付、私聊、好评三种截图<br>80 分：客户是谁 → 卡在哪 → 怎么选的 → 我怎么帮 → 结果 → 喊话同类人<br>120 分：有反差、有细节的真实成交故事 | 王婆卖瓜最没用，要让客户替你说 |
| | ⑤ 生产过程 | 晒时间、版本、现场、标准、结果，两句话配一张图 | “越贵越要讲流程”。客户要优惠，其实是想要确定感，确定感来自持续在场 |
| | ⑥ 势能背书 | 让比你厉害的人或事替你站台：被谁邀请、和谁合作 | 要平等的姿态；反例是偷拍合影、谎称合作 |
| | ⑦ 互动钩子 | 结尾留一个低门槛动作：觉得有用点个赞、想要的扣 1 | 扣 1 的人打标签，马上私聊一句。高客单不要主动追杀 |
| | ⑧ 超级钩子 | 送一份用户想要、你没成本、领完觉得有用的资料 | 截几页图发出去，“想要的私信我”，领的人都打标签 |

### 3. 他批评的发法
- 只发产品海报、活动通知、倒计时、“最后三个名额”。
- 像超市喇叭一样促销：“打折了，快来买，速抢”。
- 证言只夸客户；支付截图配“太好了，又成交一单”；私聊截图配“快来找我吧”。
- 用学历、奖项证明自己专业；只晒大合照。
- 按点赞数判断好坏，想让所有人都喜欢。
- 一天只发一条，一上来就卖，什么都想讲。

### 4. 条数和写法
- 还没养成习惯的，“三条起步”，三条分别是案例、好消息、服务过程。已经每天发 5–10 条的，营销类不超过一半。
- 高客单“永远要更克制”；“与我有关，对我有用”；不求所有人喜欢，只求被一小撮人特别需要。

### 5. AI 怎么用
- AI 写得有 AI 味，是因为“它不知道你是谁”。先给它你的业务档案和你自己写过的原创内容，再让它写。
- **一鱼多吃**：一条朋友圈被验证有效（点赞多或者咨询多），再改成短视频口播稿、小红书笔记、公众号文章。
- AI 替代不了你的经历和判断，前提是你自己分得清好坏。

## 二、叶秋轩：私域销售成交工作坊（朋友圈部分）

### 1. 朋友圈的三个作用
1. **让客户围观你**：天天在场，慢慢种草。
2. **制造开口点**：客户点赞、评论了，你就有理由私聊。“朋友圈不是单向的广播。”
3. **辅助成交**：每天发好评、成交截图、交付过程。

一句话：**朋友圈负责铺信任，私聊负责收业绩。**

### 2. 门面六件套（先装修，再发内容）

| 门面 | 怎么做 | 不要这样 |
|---|---|---|
| 昵称 | 好记，有辨识度。名字后面可以加“@近期活动”做软广，活动换了就改 | 只有一个名字，看不出是做什么的 |
| 头像 | 真人，好看一点，亲切 | 卡通头像（大 IP 是特例，普通人别学）；头像上打广告 |
| 背景图 | 有情绪或者有价值 | 放自己的海报。硬广会让越有钱的客户越走 |
| 置顶朋友圈 | 一条“我是谁、做什么”的介绍，软软地放进真实数据 | 太直接的硬广 |
| 个性签名 | 一句话证明你不是机器人 | 直接写“在卖什么” |
| 拍一拍 | 后缀放一句轻松的软植入 | — |

**好友通过后的第一句话**：先问对方从哪看到你的；再发一段自我介绍（一段话加一张图，不超过一屏的三分之二）；最后问一个低压力的问题。不要一句不说，也不要一上来就发报价、链接、PDF。

### 3. 怎么发
- **什么都可以发**：生活、创业感悟、亲子、案例、好评、深夜感悟；多发自拍，但不用每条都自拍。
- **留钩子**：正文发完，在评论区补一句。例如“如果你也卡在××，可以私信我聊聊”，或者“想要这份资料的点个赞，我一个个私你”。至少每天或每两天一条。
- **条数和时间**：
  - 每天 5 条：上午至少 1 条，下午 2 条，晚上 2 条，不要十分钟内连发完。
  - 营销内容约占一半。
  - 时间按自己客户的作息调整。
- **互动**：点赞的人就是高意向客户，要私聊跟进。客户来领资料，先聊几句、看看他的朋友圈，再给资料。

### 4. 原则和配套
- 三个原则：数量比质量重要；营销内容可以占一半，但不能写得太差；IP 本人必须自己写。
- 标签：不遗漏、不重复、简单用。已付费的客户打产品标签，发营销内容时可以对他们屏蔽。
- 防折叠：不发过度营销的内容；几个号不要复制同一段文案。
- 不回消息的客户，“用朋友圈养着”；复购和转介绍，也靠朋友圈持续提醒。

## 四、讲师原话里要改的一处
- 原话：“刷屏的朋友圈，腾讯会把你屏蔽掉、折叠起来。”
- 改成：“**微信会折叠，客户会屏蔽。**”
  - 微信会把短时间内连发的多条收起来，只显示“余下 X 条”。腾讯客服的说法是：频繁发广告营销内容会被折叠，点开才能看全。
  - “屏蔽”是客户自己点的“不看他的朋友圈”。
  - 来源：[人人都是产品经理](https://www.woshipm.com/operate/5330186.html)、[IT之家](https://www.ithome.com/0/598/314.htm)。
- 折叠的条数、时间间隔没有官方数字，课上不要说具体数字。
