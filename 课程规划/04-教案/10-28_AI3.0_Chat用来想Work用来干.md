## 为什么这节课现在讲
- **AI 已经从“会聊天”走到“会干活”。** 桌面智能体能读你的文件、改表格、批量出东西、定时执行。可大部分学员还把 AI 当聊天框用，问一句答一句。
- **前两节课都差一个 AI 演示。**
  - 10/7 朋友圈课：提示词没讲解，结果没翻完，怎么改掉 AI 味没讲。
  - 10/14 定位课：说了“选题往 AI 里一输，内容立马出来”，没有演示。
  - 这节课用同一套方法把这两件事补上。
- **零件都讲过，没讲过怎么分工。**
  - 03-19 讲过“普通 AI 是小工，智能体是包工头”。
  - 06-10、08-12 讲过 WorkBuddy、文件夹即智能体、计划模式。
  - 这节课回答一个更基础的问题：什么事用 Chat，什么事用 Work。

## 开场（00–03）· 同一个任务，两种结果
- 投屏两张截图。任务都是：“根据这段录音，帮我写下周 7 条朋友圈”。
  - Chat：给了一大段文字，要你自己复制、整理、存。
  - Work：直接在文件夹里放好一张表格，周一到周日、正文、配图建议都排好了。
- 可以这样说：“同样是 AI，一个陪你聊，一个替你干。今天就讲清楚：什么时候聊，什么时候派活。”
- 公屏：你现在用 AI 最多干什么？
  1. 问问题
  2. 写文案
  3. 做图
  4. 基本没用

## 第一部分（03–10）· AI 是什么，走到了哪一步

**AI 是什么**（用大白话讲）：
- 可以把大模型想成一个读过海量资料的实习生：聪明、勤快、不睡觉。
- 但它不认识你的店、你的客户，也不知道今天的行情。不懂的时候，它会一本正经地编。
- **模型是大脑，工具是工位。**
  - 模型：DeepSeek、豆包、Kimi、智谱这些。
  - 工具：豆包 App、AI 大脑、WorkBuddy。
  - 同一个大脑，坐在不同的工位上，能干的活不一样。
- 积分和 Token 就是成本（02-11、04-08 讲过），用多少花多少。

**三个阶段**（这是你的讲法，不是行业标准说法，课上可以说“我自己是这么分的”）：

| 阶段 | 大概的时间 | 它会什么 | 你怎么用 |
|---|---|---|---|
| 1.0 会聊天 | 2023 年前后 | 问一句答一句，写写文案 | 当搜索框、当写手 |
| 2.0 会思考 | 2025 年前后 | 深度思考、联网查资料，能推理、搭框架 | 当参谋 |
| 3.0 会干活 | 现在 | 在你电脑上读文件、改表格、批量出东西、定时执行，交给你做好的东西 | 当员工 |

- 可以这样说：“大部分人还停在 1.0：把 AI 当搜索框，问完复制粘贴。今天要升两级。”

## 第二部分（10–20）· Chat 和 Work 有什么区别

| | Chat 模式 | Work 模式 |
|---|---|---|
| 像谁 | 参谋、军师：陪你想 | 包工头、员工：替你干（03-19 讲过“包工头”） |
| 你给它什么 | 一个问题、一段想法 | 一个文件夹，加一件交代清楚的活 |
| 它交给你什么 | 一段回答、一个思路、一版框架 | 做好的文件：表格、文案合集、报告 |
| 怎么用 | 来回追问，让它反问你 | 先把标准讲清楚，最后验收 |
| 适合什么事 | 还没想清楚的事 | 已经想清楚的、重复的、量大的事 |
| 常用工具 | 豆包、DeepSeek、Kimi 的对话框，AI 大脑 | WorkBuddy 这类桌面智能体 |
| 最大的风险 | 一本正经地编 | 动错文件；把隐私交出去 |

- 可以这样说：“想不清楚的事，别急着派活。派活之前想清楚，想清楚了就别再一句一句聊，直接派。”

### 二奢老板的分工清单

| 用 Chat 想 | 用 Work 干 |
|---|---|
| 定位：用 10/14 的三角图（人设、人群、需求）让 AI 问你问题，帮你写定位句 | 一段录音逐字稿 → 一周 7 条朋友圈 + 选题表（10/7 的提示词） |
| 活动方案：双 11、年底清库存，先让它搭框架 | 批量上新文案：一个文件夹的货品信息 → 每只一段描述 |
| 话术和陪练：让 AI 扮演砍价、白嫖估价的客户，你来接 | 库存表 → 超过 30 天的货列出来，加处理建议（07-15 周转纪律） |
| 选题：一个爆款只换人群、换品牌，出 30 个 | 脱敏后的成交记录 → 客户分层表，方便打标签 |
| 复盘：把这个月的几个数字说给它，让它问你问题 | 直播回放逐字稿 → 切片选题 + 口播稿 |
| 学新东西：新规、新平台规则（最后要看原文） | 定时任务：每天早上把当天朋友圈推到微信，每周一出库存周报（03-24、06-24） |

- 可以这样说：“左边那一列，你得在场，它是陪你想。右边那一列，交代清楚就可以走开，回来验收。”

## 第三部分（20–30）· 八个错误认知

| # | 错误认知 | 真相 |
|---|---|---|
| 1 | AI 就是个聊天的 | 3.0 已经能干活，交给你的是做好的文件 |
| 2 | AI 什么都懂 | 它不懂你的店、你的客户、今天的行情，还会编。价格、行情、规定，一律自己核实（03-24 讲过 AI 预测行情的边界） |
| 3 | 一句话就能出好东西 | 不给背景、不给素材，它只能写出谁都能写的东西。你给它多少，它还你多少 |
| 4 | AI 写的可以直接发 | 客户看得出 AI 味，回复像 AI 会丢单（10/7 讲过）。AI 出初稿，你过嘴改稿（05-13） |
| 5 | 工具越多越好，天天追新 | 差生文具多（04-08）。一个 Chat 工具、一个 Work 工具，用熟就够 |
| 6 | AI 能帮我辨真假、定价格 | 它不能拍板。看货、定价、收不收，最后都是你。它只能帮你把依据整理好 |
| 7 | AI 会抢我饭碗，或者我学不会 | 它抢的是重复的活。会说话就会用 AI（03-19：表达能力是第一生产力） |
| 8 | 资料随便丢给它都没事 | 身份证、手机号、银行卡、客户聊天原文不进 AI。Work 模式只给它一个文件夹，不让它删东西（06-10 沙箱、08-12 文件夹即智能体） |

### 能做 / 不能拍板

| 放心交给它 | 必须你拍板 |
|---|---|
| 写初稿、改稿、换说法 | 这只包是真是假 |
| 整理、汇总、做表格 | 最终报价，收不收 |
| 批量出东西、定时提醒 | 和客户建立信任 |
| 出框架、出选题、陪你练话术 | 发出去的东西合不合规（责任在你） |
| 帮你想没想到的角度 | 客户故事和成交数字（只能来自真实发生的事） |

## 第四部分（30–36）· 怎么用：先想后干五步

1. **在 Chat 里想清楚**：让它反问你，把方向、标准想明白（02-25 讲过“让 AI 反问你”）
2. **把想清楚的写成规则**：写成一份提示词，或者一份档案
3. **交给 Work 批量干**：一个文件夹，一件交代清楚的活
4. **你来验收、改稿**：看三样
   - 有没有编
   - 有没有 AI 味
   - 有没有违规
5. **把改过的地方写回规则**：下次它就按你的标准干（07-01 规则固化）

**为什么要这么做**：
- 不想清楚就派活，它会很快干出一堆你用不上的东西。
- 想清楚了还一句一句聊，你自己就成了搬运工。
- 规则写一次，以后每次都按你的标准来。规则攒多了，就是下次要讲的 Skill。

## 第五部分（36–44）· 演示 1（Chat）：让 AI 反问你，写出定位句

**提示词①：写定位句**（课后发群）

```
你是二手奢侈品行业的经营顾问。我想写一句店铺定位，格式是：我是谁 + 帮什么样的客户 + 解决什么问题。
先不要写。请一次只问我一个问题，围绕三件事问清楚：
1. 我的人设：我专业在哪里，我懂客户的什么顾虑
2. 我的人群：手里有货的人还是要买的人，急不急，买不买得起
3. 客户的需求：他要什么结果，这个结果能不能用数字说清楚
问完 5–8 个问题后，给我 3 句定位备选，说明每句适合什么阶段的店。
```

**提示词②：出选题**（接着在同一个对话里发）

```
用你刚才给的第 1 句定位，按“换人群”的方法给我 30 个短视频或朋友圈选题：
同一个客户痛点，分别换品牌（LV、古驰、香奈儿……）、换人群（上班族、白领、应届生、宝妈……）。
每个选题一行，标注是给想出手的人，还是给想买的人。不写鉴定类选题。
```

- 现场用你自己的店答问题，学员看 AI 怎么一步步问。
- 讲点：
  - 这就是 Chat 的用法：它问，你答，你在场。
  - 10/14 讲的三角图，到这里就能落地了。

## 第六部分（44–48）· 派活五件套

给 Work 派活，交代这五样，它才干得像你：

| 件 | 是什么 | 在《朋友圈提示词》里对应哪一节 |
|---|---|---|
| 背景 | 我是谁、我的店、我的客户 | 零、我的档案 |
| 素材 | 录音、表格、照片 | 逐字稿文件 |
| 要求 | 格式、字数、红线 | 二、核心铁律；七、写作硬性要求 |
| 例子 | 我写过的好东西 | 档案里的 3–5 条朋友圈 |
| 验收标准 | 什么样算合格 | 十一、交付前自查清单 |

- 02-11 讲过“提示词五要素”，这是给 Work 派活的版本。
- 可以这样说：“你看这份提示词很长，但拆开就是这五样。写一次，以后每周都能用。”

## 第七部分（48–56）· 演示 2（Work）：一个文件夹，出一周朋友圈

**派活的话**（在 WorkBuddy 里，选中“10-28演示”这个文件夹）：

```
读这个文件夹里的《朋友圈提示词》和录音逐字稿，按提示词的规则写下周 7 条朋友圈。
存成一张表格放回这个文件夹，列是：周几、类型、正文、评论区补一句、配图建议、建议可见分组、备注。
不要改动、也不要删除文件夹里原有的文件。
```

- 打开生成的表格，挑一条现场过嘴改稿：
  - 删掉 AI 腔
  - 把长句改短
  - 换成你平时说话的口气
- 把改的地方说给它听：“以后都别用‘不得不说’，句子再短一点。”这就是先想后干的第 5 步。
- 时间够的话，加**演示 3**：一张库存表，让它列出超过 30 天的货，按压款金额排序，每只给一句处理建议。
  - 用示例数据，或者脱敏后的真实表。

## 收尾（56–60）· 作业 + 预告
