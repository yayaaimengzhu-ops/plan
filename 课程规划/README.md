# 周三课第四季度规划（2026-10 → 2027-01）

依据：仓库根目录上传的 2026-01-25 到 09-23 的课程总结和逐字稿（25 节正课）。

## 一页结论

1. **三个板块严重失衡**：获客讲了 13 节，AI 讲了 9 节，经营只有 3 节。年底正是盘库存、算账、定计划的时候，第四季度要往经营倾斜。
2. **选题方法已经讲饱和了**：九宫格讲了 4 次，选题为王讲了 5 次。获客接下来要讲前面没讲透的环节：私聊成交、投流、门店、私域收割。
3. **年初承诺了 10 项还没兑现**：鉴定、防骗、门店话术、Skill 专场、报价 APP、ChatCut 教程等。第四季度兑现其中 8 项，剩下 2 项放进 2027。兑现承诺是续费最好的理由。
4. **学员卡点**：讲得多的是“没灵感、没流量”，没专门讲过的是“有咨询没成交、钱周转不过来、舍不得亏着卖、要不要招人、行情差很迷茫”。
5. **AI 工具换得太快**：从龙虾、WorkBuddy、豆包桌面版到 ChatCut……1/20 做一次“工具减法”。
6. **有一处要更正**：08-05 总结里的“莫奈奶白”，查证后是 **LV 起诉茶饮品牌“茉莉奶白”的商标案**，7 月引发抵制、二手 LV 价格跳水。不是改色案。其他需要更正的地方见《02-缺口诊断》第 7 节。

## 每周备课建议
1. 打开排课表找到这一周，看“承接旧课”，回顾那节的总结（2 分钟就够）。
2. 过一遍“讲前核实清单”，核实不了的数字不讲。
3. 讲师判断的部分一定用自己的话、自己店里的例子。
4. 上完课把总结和逐字稿放回仓库，下个季度再用同样的方法复盘。

> 教案里标着“可以这样说”的句子都是草稿，按你的口头禅改（05-13 过嘴改稿）。
